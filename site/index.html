The subsystem

Durable control plane.
Disposable execution.

Rat Things turns authenticated API calls and signed GitHub, GitLab, Teams, or Slack webhooks into durable agent runs.

DynamoDB, S3, SQS, Streams, and EventBridge retain the state. AWS Lambda MicroVMs provide one isolated execution environment per job. Results return to the thread that asked.

Data flow

Webhook to answer, without a permanent worker.

  1. 01Authenticate

    Verify IAM or provider signatures and normalize identity.

  2. 02Persist

    Commit the request and artifacts before dispatching work.

  3. 03Isolate

    Launch one Lambda MicroVM and run Codex as an unprivileged user.

  4. 04Deliver

    Store output, publish completion, and reply to the source thread.

Engineering preview

Isolation is a boundary, not a permission slip.

Treat prompts, repositories, model output, and webhook fields as untrusted. Production still requires an independent IAM and malicious-repository review, budgets, outbound policy, output redaction, and destination authorization.
