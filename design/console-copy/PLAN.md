# Native UI copy pass

Apply stageshow's restraint principle to the shipped Rust console. Review every
native presentation module: welcome/navigation, creation, resource details,
conversation/activity, artifacts/browser feedback, workspace/account setup,
copy/share, environment/model pickers, and recovery/deletion states.

Keep text when it identifies the current object, tells the user what to do,
explains a meaningful choice or consequence, or helps recovery. Remove headings
and captions that merely restate controls. Shorten promotional and implementation
language. Put occasional technical context in existing tooltips/disclosures.
Preserve local/cloud behavior, credential privacy, attribution provenance,
fixed capabilities, authority checks and destructive/transfer consequences.

No data, backend, prompt, permission or API behavior changes. Keep useful empty
states and accessible control names. Native screenshots at 1280×850 and 900×650
show the result; update copy-sensitive tests, run native and repository checks,
and ask a fresh subagent to inspect source copy and the rendered screens.

Use the existing ai-chat/panel-annotation references and actual native controls.
This is an editorial pass, not a new authored animation or a mobile client.
